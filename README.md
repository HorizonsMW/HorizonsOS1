# HorizonsOS1

A Hyprland + Noctalia desktop setup for Arch Linux (Wayland), with Dunst notifications and Swappy screenshots. Theme: "Golden Gate" — frosted glass surfaces with a warm gold accent.

## What's included

| Folder             | Installs to            | Contents                                            |
|--------------------|------------------------|-----------------------------------------------------|
| `config/hypr`      | `~/.config/hypr`       | `hyprland.lua` (Lua config), `monitors.lua`, `workspaces.conf` |
| `config/noctalia`  | `~/.config/noctalia`   | `config.toml`, `palettes/GoldenGate.json`           |
| `config/dunst`     | `~/.config/dunst`      | `dunstrc` (iOS-style bubble notifications)          |
| `config/swappy`    | `~/.config/swappy`     | `config` (saves to `~/Pictures/Screenshots`)        |

## Requirements

```bash
sudo pacman -S --needed hyprland dunst libnotify swappy grim slurp kitty nautilus wofi hyprpaper hyprpolkitagent udiskie blueman
```

Plus [Noctalia](https://docs.noctalia.dev) (AUR). The Hyprland config also launches Zen Browser, Mission Center and EasyEffects via Flatpak, and ProtonVPN — remove those lines from `hyprland.lua` if you don't use them.

## Install

```bash
git clone https://github.com/<you>/HorizonsOS1.git
cd HorizonsOS1
sudo ./install.sh
```

Options:

| Flag              | Effect                                                     |
|-------------------|------------------------------------------------------------|
| `-y`, `--yes`     | Overwrite without prompting (backups are still made)       |
| `-n`, `--dry-run` | Print what would happen, change nothing                    |
| `-h`, `--help`    | Show help                                                  |

### What the installer does

1. Checks it is running under `sudo` and resolves the real user from `$SUDO_USER` (so files go to your home, not `/root`).
2. Creates `~/.config` if it's missing.
3. For each config folder:
   - If it doesn't exist, it's created and the configs are copied in.
   - If it exists, you're asked whether to overwrite. On yes, every file that would be replaced is renamed to `<file>.bak` (or `<file>.bak.<timestamp>` if a `.bak` already exists), then the repo files are copied in. Files not in the repo are left alone.
4. Fixes ownership so everything belongs to your user.
5. Reloads the running session: `hyprctl reload` for Hyprland, restarts Noctalia, reloads/restarts Dunst and sends a test notification. Swappy has no daemon and picks up the config on next launch.

### Restoring

```bash
mv ~/.config/dunst/dunstrc.bak ~/.config/dunst/dunstrc
```

## Notes

- `config/hypr/monitors.lua` is generated by nwg-displays for a 1920x1080 `eDP-1` panel. Regenerate it for your own monitors.
- For real glass blur on Noctalia, keep layer-shell blur enabled for the Noctalia namespace in Hyprland.
